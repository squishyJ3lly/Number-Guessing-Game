This is a very simple number guessing game. It has game modes:
-   Easy,
-   Medium,
-   Hard,
-   Extreme

There are 2 run options:
-   src/main.py
or
-   dist/main.exe

You don't have to read this next part, but you can if you want to.

The executable "main.exe" is a standalone executable. It doesn't require Python
like src/main.py does, src/main.py requires python but is only about 3KB in size.
While dist/main.exe is about 7MB in size.
